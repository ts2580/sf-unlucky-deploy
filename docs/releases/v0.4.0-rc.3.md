# sf-unlucky-deploy v0.4.0-rc.3

npm 시험 배포 대상: `@trstyq/sf-unlucky-deploy@0.4.0-rc.3`, dist-tag `next`.

- Windows 홈 설정 권한 검사에서 멈추던 PowerShell 파일 공급자 호출을 .NET 파일·ACL API로 교체.
- ACL 하위 프로세스의 비동기 실행, 환경 격리, 제한 시간 및 민감정보를 제외한 단계별 오류 진단 추가.
- Windows CLI 회귀 검사의 Node 로더 경로를 file URL로 변환하고 Windows 시작 시간 반영.
- RC는 최신 `canary`, 정식 버전은 최신 `main`의 annotated tag에서 GitHub Release 생성.
- npm 발행 시 RC·정식 소스 브랜치와 GitHub Release의 prerelease 상태 검증 추가.

## 설치

registry 발행 완료 후 다음 명령으로 설치한다.

```bash
npm install --global --allow-scripts=sqlite3 @trstyq/sf-unlucky-deploy@0.4.0-rc.3
sfud --version
```

Node.js 22.19.0 이상, Salesforce CLI v2와 Git이 필요하다. 기존 RC2는 덮어쓰지 않으며 이번 발행은 npm `latest`를 이동하지 않는다.

## 릴리스 검증

GitHub Release 워크플로에서 타입·단위·브라우저 테스트를 수행하고, 동일한 tarball을 Linux Node 22.19/24, Windows Node 24, macOS ARM64 Node 24에서 설치 검증한 뒤 공개한다. npm에는 이 GitHub Release의 tarball을 사용한다. 실제 Salesforce Org 인증·배포는 해당 설치 검증에 포함되지 않는다.
