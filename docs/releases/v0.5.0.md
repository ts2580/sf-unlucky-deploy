# sf-unlucky-deploy v0.5.0

배포 대상 메타데이터와 테스트 클래스의 저장·복원, 선택 항목 비교, Markdown diff 다운로드를 추가한 마이너 버전이다.
이 문서는 `canary` 검증을 위한 변경 내역이며, 정식 태그·GitHub Release·npm 발행은 별도 절차로 진행한다.

## 주요 변경 사항

- 배포 설정에 선택한 메타데이터 타입·이름과 테스트 클래스 목록 저장
- 설정을 불러오면 원격 조회 없이 메타데이터 검색 아래에 저장한 배포 항목, Apex 테스트 설정에 저장한 테스트 클래스 즉시 표시
- 불러온 목록에서 체크한 항목만 비교하거나 비교 없이 직접 배포 가능
- 실제 비교·검증·배포를 실행할 때 Git 소스 준비와 Org identity 확인 수행
- 배포 클래스 선택이나 테스트 입력란 포커스 없이 준비된 소스의 Apex 클래스 목록 표시
- 현재 검색·상태 필터의 모든 페이지와 개별 파일 diff를 Markdown으로 다운로드
- XML semantic 정책 진단을 화면과 HTML 리포트에서 숨기고 비교 결과와 필요한 안내 표시
- 탭별 선택 초안 관리 메뉴를 정리하고 이전 선택이 있을 때 복원 안내 표시

## 기존 설정

기존 배포 설정은 계속 불러올 수 있다. 배포 항목이 저장되지 않은 기존 설정은 항목과 테스트 클래스를 선택한 뒤 **현재 설정으로 갱신**하여 목록을 저장한다.
불러오기만으로 원격 메타데이터의 존재 여부를 확인하지 않으며, 실제 작업 시 소스 준비와 검증 오류를 안내한다.

## 검증 범위

타입·정적 검사, 단위·API 검사, PC·모바일 브라우저 회귀 검사를 수행한다.
자동 검사의 배포 요청 검증과 실제 Salesforce Org 배포 결과는 구분한다.
