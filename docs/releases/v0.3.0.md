# sf-unlucky-deploy v0.3.0

배포 상태 복구와 실행 저장소 관리를 보강하고, 대화면과 모바일에서 웹 콘솔의 가독성을 개선한 마이너 버전이다.

## 주요 변경 사항

- Salesforce 작업을 재제출하지 않는 완료 상태 저장 재시도 및 복구
- 런타임별 실행 저장소 격리와 주기적 정리, 실행·승인 대기 payload 보호
- 결과 파일 만료 시 작업 조회와 배포 상태를 유지하는 처리
- 배포 모델·artifact 조회·실시간 화면 갱신 로직의 전용 모듈 분리
- Source/Target 차이 표시와 Source-only 메타데이터 조회 개선
- 2K 작업 공간과 글자 크기 확대, 320~430px 모바일 넘침·줄바꿈 수정
- 작업 현황 최상단 배치, 배포 안내 간소화, 비교 옵션과 받아오기 버튼 크기 통일
- 테스트 수준별 실제 배포 안내와 테스트 미선택 시 실행 제한 정합성 개선

## 설치

릴리스 산출물의 체크섬을 확인한 뒤 설치한다.

```bash
sha256sum --check SHA256SUMS
npm install --global --allow-scripts=sqlite3 ./sf-unlucky-deploy-0.3.0.tgz
sfud --version
```

Node.js 20.19 이상과 Salesforce CLI v2가 필요하다. `sqlite3` native binding 설치 스크립트만 명시적으로 허용한다.

## 운영 시 참고

- 기존 데이터베이스와 실행 기록은 유지하며, 만료된 파일은 저장소 정책에 따라 정리
- 실행 중·재확인 대기 작업과 유효한 승인 payload는 정리 대상에서 제외
- 실제 배포 권한과 대상 org 확인, 테스트 조건 및 TARGET ONLY 선택 제한 유지
- 브라우저를 닫아도 이미 제출된 Salesforce 배포는 취소되지 않음
- SQLite와 단일 프로세스 큐 기반으로 다중 인스턴스 수평 확장은 지원하지 않음
