# sf-unlucky-deploy v0.4.0-rc.1

npm 최초 시험 배포 후보. 현재 로컬 준비 상태이며 registry 발행은 완료되지 않았다.

## 주요 변경 사항

- npm CLI·UI 통합 패키지, 설치 잠금 파일 및 단일 tarball 검증 흐름 보강
- `sfud config init/path`, 사용자 홈 config.json과 선택적인 secrets.env 지원
- CLI → 환경변수 → 홈 설정 → 기본값 우선순위, 홈 기준 데이터 경로 제공
- 설정 파일 권한·소유자·링크·크기 검사, 비밀값과 일반 설정 분리
- LOCAL 루프백 및 기존 DB 모드 분리, 암호화 키와 기존 파일 보존

## 배포 및 설치

배포 대상은 `@trstyq/sf-unlucky-deploy@0.4.0-rc.1`, 채널은 `next`이다. 공개 registry 발행 이후 다음 명령으로 설치한다.

```bash
npm install --global --allow-scripts=sqlite3 @trstyq/sf-unlucky-deploy@0.4.0-rc.1
sfud config init
sfud ui
```

Node.js 22.19.0 이상, Salesforce CLI v2와 Git이 필요하다. 일반 설치의 기본 채널인 latest 승격은 정식 버전 검증 후 별도로 진행한다.

## 검증과 남은 조건

이전 0.4.0 로컬 후보의 홈 설정·암호화·SQLite 회귀 73개와 설치 보안 시나리오(Node 22.19/24 각 40개)는 이전 버전 산출물의 증거다. RC 버전·CLI·잠금 파일 동기화, 빌드 및 산출물 검증을 다시 수행한다.

프로젝트 라이선스는 사용자가 MIT로 확정했으며 공개 발행 플래그 private=false를 반영했다. 현재 환경은 npm registry DNS 조회가 EAI_AGAIN으로 실패한다. 전체 verify·실제 서버 기동과 Windows/macOS 검증은 환경 제한으로 완료되지 않았다. 실제 registry 설치·provenance 검증 완료로 취급하지 않는다.
