# sf-unlucky-deploy v0.4.0-rc.2

npm 시험 배포 대상: `@trstyq/sf-unlucky-deploy@0.4.0-rc.2`, dist-tag `next`.

- 실제 첫 실행에서 Linux/Windows 사용자 홈의 `.sfud/config.json`과 주석 안내용 `secrets.env` 자동 생성. 기존 파일 보존 및 사용자 전용 권한 검사.
- Git/Salesforce 암호화 키를 `SFUD_TOKEN_SECRET`으로 통합. 기존 개별 키는 공통 키가 없을 때 호환. 두 이전 키 값이 다르면 이전 키 유지 또는 새 공통 키로 인증 재등록 필요.
- 연결 이름·행 클릭으로 Git/Salesforce 설정 편집. 별칭 변경과 새 인증 검증 후 연결 대상 변경. 소유자·변경 세대 검사로 실패·중복·동시 변경 보호.
- 계정 범위 Git 연결 저장 직후 저장소 목록 조회. 기존 계정 연결 설정에서도 목록 조회, 저장소 선택과 브랜치 확인·등록·가져오기 제공.
- 별칭 입력의 `예: 커넥스 운영` 제거.
- Salesforce 인증 목록의 5초 만료 제거. 서버 실행 동안 사용자별로 탭 이동·새 브라우저 세션·재로그인 간 재사용. 명시한 새로고침과 연결 변경 시 갱신. 배포 직전 대상 Org 재확인 유지.

## 설치

registry 발행 완료 확인 후 다음 명령으로 설치한다.

```bash
npm install --global --allow-scripts=sqlite3 @trstyq/sf-unlucky-deploy@0.4.0-rc.2
sfud --version
```

이 RC는 안정 배포가 아니며 `latest`를 이동하지 않는다. 서버 재시작 후 최초 인증 목록 조회는 다시 수행한다. 외부 sf CLI에서 인증을 변경했으면 인증 관리에서 새로고침한다.

## 검증 범위

관련 회귀 10개 파일 90개 통과, Windows 전용 1개는 Linux에서 제외. 타입·품질·저장소 루트 빌드·버전/잠금 파일 동기화 통과. 제한 환경의 로컬 네트워크 EPERM으로 Playwright 실행 차단. 패키징 정책 7개 통과, manifest 하위 프로세스 테스트 1개는 spawnSync EPERM으로 차단. 실제 Salesforce Org·외부 Git 제공자 인증은 로컬 fixture 결과에 포함하지 않는다. CI에서 Linux/최소 Node/Windows 및 브라우저 검증을 확인한 뒤 병합한다.
