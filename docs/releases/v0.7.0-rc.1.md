# sf-unlucky-deploy v0.7.0-rc.1

Git 비교 흐름과 Windows 프로젝트 가져오기, 설치 패키지별 비교 제외를 개선한 0.7.0의 첫 RC.
canary 기반 GitHub prerelease 및 npm `next` 발행 대상.

## 주요 변경 사항

- Git 비교에서 브랜치를 먼저 선택하고, 메타데이터 타입을 선택해 비교를 실행할 때 해당 코드를 가져오도록 변경.
- 브랜치 검색 중 안내와 스피너 표시. 여러 DX 프로젝트 중 하나를 고르는 동안 메타데이터 타입 변경을 잠가 미완료 가져오기의 누적 방지.
- 셀프 호스팅 GitLab 연결 오류 안내 개선. 저장소 하나를 연결할 때 그룹과 저장소 경로를 포함한 HTTPS URL 사용.
- 관리자 설정에 Git 사설 IP 검사 추가. 기본값은 검사 안 함이며, 검사 활성화 시 허용 IP 목록 적용.
- Windows에서 임시 프로젝트 폴더를 최종 위치로 이동하던 단계를 제거하고 최종 경로에 파일 직접 복원. 정리 재시도 후에도 잠금이 남으면 원래 가져오기 오류 보존.
- 패키지 로딩 버튼으로 설치 패키지의 실제 메타데이터 구성요소 조회·검색 지원. 네임스페이스가 없거나 다른 패키지와 공유해도 구성요소 확인 후 개별 제외 지원.
- 전체·CustomObject 비교에서도 제외 패키지의 하위 필드·규칙·라벨만 제거하고 다른 구성요소의 차이와 원본 파일 보존.
- 패키지 조회 중 Org 변경이나 연결 종료 시 진행 중 조회 취소. 버전·연결별 캐시와 권한 재확인 적용.
- 개인용 `sfud config init`에서 UUID v4 암호화 키 자동 생성. 기존 설정과 암호화 키 보존.
- README와 설정·Git·CLI 사용 문서 갱신.

## 설치 및 전환

npm 발행과 registry 검증 완료 후 일반판 설치:

```bash
npm install --global --allow-scripts=sqlite3 @trstyq/sf-unlucky-deploy@0.7.0-rc.1
sfud --version
```

Node.js 22.19.0 이상, Salesforce CLI v2와 Git 필요.
이 RC는 npm `next` 대상이며 정식 `latest` 승격은 별도 진행.
SQLite 포함 Windows x64 번들 버전은 `0.7.0-rc.1.win32-x64.1`로 구분하며,
일반판 Release tarball 확정 후 원본 커밋과 체크섬을 고정해 별도로 검증·발행.

업그레이드 전 데이터 디렉터리와 홈 설정 백업 필요.
DB 마이그레이션 49로 Git 사설 IP 검사 설정 추가. 기본값은 검사 안 함이므로,
Git 접근을 허용 IP로 제한해야 하는 환경에서는 관리자 설정에서 검사를 활성화하고 허용 목록 확인.
설정은 관리자 Git 연결 설정에서 변경 가능하며 Salesforce 연결 정책과 별도로 관리.
기존 데이터와 암호화 키 유지. 이전 버전 복귀 시 백업한 DB와 설정을 함께 복원.

패키지 구성요소 로딩은 연결한 Org에서 참조용 패키지를 조회하며 배포하지 않음.
같은 Org에서 표시 이름이 같은 패키지를 구분할 수 없거나 조회 결과가 불완전하면 개별 제외 중단.

## 검증 범위

GitHub Release 워크플로에서 타입·단위·브라우저 검증 후 동일한 tarball을
Linux Node 22.19/24, Windows Node 24, macOS ARM64 Node 24에서 설치·CLI·UI·SQLite·재시작 검증.
tarball, SHA-256 체크섬, SBOM과 원본 manifest를 Release에 첨부하고 npm에 동일 tarball 발행.
실제 Salesforce Org 전체 패키지 조회·배포는 자동 검증 범위에 포함하지 않음.
