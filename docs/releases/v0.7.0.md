# sf-unlucky-deploy v0.7.0

Git 비교·Windows 프로젝트 가져오기·설치 패키지 제외를 개선하고, 개인용 초기 설정과 UI 종료 명령을 추가한 정식 버전.

## 주요 변경 사항

- Git 브랜치를 먼저 선택하고 메타데이터 비교 실행 시 코드를 가져오도록 변경. 브랜치 검색 안내와 프로젝트 선택 중 메타데이터 타입 잠금 적용.
- 셀프 호스팅 GitLab URL 오류 안내 및 관리자 Git 사설 IP 검사 설정 추가. 사설 IP 검사는 기본적으로 비활성화하며, 활성화하면 허용 목록 적용.
- Windows에서 임시 폴더 이동 없이 최종 프로젝트 경로에 파일 직접 복원. 정리 실패 시 원래 가져오기 오류 보존.
- 설치 패키지의 구성요소 조회·검색과 개별 제외 지원. 고유 네임스페이스 패키지는 조회 없이 제외하고, 네임스페이스가 없거나 공유하는 패키지는 구성요소 확인 후 제외.
- 필요한 패키지만 최대 3개씩 병렬 조회하고 진행 건수·패키지 이름 표시. 전체 제외 선택·해제와 데스크톱·모바일 목록 배치 개선. 조회 실패 시 기존 선택 보존, Org 변경·연결 종료 시 진행 중 조회 취소.
- 전체·CustomObject 비교에서도 선택 패키지의 하위 필드·규칙·레이블만 비교에서 제외. 원본 파일과 배포 파일 보존.
- 새 환경의 첫 `sfud ui` 실행과 `sfud init`에서 개인용 `LOCAL=true`, 홈 설정 기준 `data/local`, UUID 암호화 키 자동 준비. 기존 설정·키와 명시한 환경변수 보존.
- 같은 OS 계정과 설정 경로의 다른 터미널에서 `sfud stop`으로 UI 정상 종료. 여러 UI는 `--port`와 필요 시 `--host`로 선택하며, 작업·DB 정리 완료 후 성공 표시.
- 읽기 전용 `sfud doctor`에서 개인용 첫 실행 기본값 점검. 설치 검사에 자동 초기화·정상 종료·다른 폴더 재시작 후 설정·키·SQLite 기록 보존 검사 추가.

## 설치 및 전환

정식 발행과 registry 검증 완료 후 일반판 설치:

```bash
npm install --global --allow-scripts=sqlite3 @trstyq/sf-unlucky-deploy@0.7.0
sfud --version
sfud ui
```

SQLite 포함 Windows x64 번들은 `0.7.0-win32-x64.1`로 구분하며, 원본 일반판 산출물 확정 후 별도로 검증·발행.

```powershell
npm install --global --ignore-scripts @trstyq/sf-unlucky-deploy@0.7.0-win32-x64.1
sfud --version
sfud ui
```

Node.js 22.19.0 이상, Salesforce CLI v2와 Git 필요. Windows 번들의 CLI 버전은 `0.7.0`.
실행 중인 UI는 업데이트 전에 종료. 이전 버전은 실행 터미널에서 `Ctrl+C` 사용.

업그레이드 전 데이터 디렉터리와 홈 설정 백업 필요. 기존 DB와 암호화 키 유지.
새 환경의 기본 DB는 `~/.sfud/data/local/sfud.db`이며, Windows는 `%USERPROFILE%\.sfud\data\local\sfud.db`.
기존 설정은 자동 전환하지 않으며, 팀 서버를 개인용으로 바꿀 때는 별도 데이터 경로 사용.
DB 마이그레이션 49에서 Git 사설 IP 검사 설정 추가. 접근 제한이 필요한 환경에서는 관리자 설정의 검사 활성화와 허용 목록 확인.
이전 버전으로 돌아갈 때는 백업한 DB와 설정을 함께 복원.

## 검증과 발행

2026-10-21 사용자가 테스트 완료와 정식 발행 요청. 자동 검증과 별개의 사용자 확인 기록.

정식 태그는 사용자 수동 PR 병합 후 최신 `main`에서 생성.
GitHub Release 워크플로에서 타입·단위·브라우저 검사 후 동일한 tarball을 Linux Node 22.19/24,
Windows Node 24, macOS ARM64 Node 24에서 설치·CLI·UI·SQLite·재시작 검증.
검증된 tarball·SHA-256 체크섬·SBOM·manifest를 Release에 첨부하고 같은 파일을 npm `next`에 발행.
Windows 번들은 원본 커밋·체크섬을 고정하고 Node 22.19/24의 오프라인 설치 검사 후 `win32-x64`에 발행.
두 산출물의 registry 바이트 검증 후 일반판 `latest` 승격.

이 문서는 정식 발행 대상의 안내이며 발행 완료 증거는 아님. 실제 Salesforce Org 전체 패키지 조회·배포는 자동 검증 범위에 포함하지 않음.
