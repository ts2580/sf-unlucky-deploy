# sf-unlucky-deploy v0.6.0

Diff 다운로드 형식 선택과 Salesforce 메타데이터 타입 조회 상태 표시를 개선한 마이너 버전.
canary 검증용 변경 내역이며 정식 태그·GitHub Release·npm 발행은 main 승격 후 별도 진행.

## 주요 변경 사항

- 전체 비교 결과와 개별 파일의 Diff 다운로드를 단일 드롭다운으로 변경
- CSV·MD·JSON 형식 선택 즉시 다운로드, 동일 형식 재선택 지원
- 현재 검색·상태 필터에 해당하는 모든 페이지의 컴포넌트 내보내기 유지
- CSV에 UTF-8 BOM, 쉼표·따옴표·줄바꿈 이스케이프와 스프레드시트 수식 실행 방지 처리 추가
- JSON에 SOURCE/TARGET 방향, 원본 diff 구조와 비교 결과 보존
- Salesforce 메타데이터 타입 조회 중 파란색 안내와 회전 아이콘 표시
- 조회 중 비교 버튼에 대기 문구 표시, 완료·실패 시 상태에 맞는 문구 복귀

## 검증 범위

- 타입·정적 검사, 단위·API 검사, CLI·UI 빌드
- PC·모바일에서 형식 선택 즉시 다운로드, 반복 다운로드와 검색 필터 범위 검증
- 메타데이터 타입 조회의 대기·완료·재조회·실패 상태와 반응형 화면 검증

기존 Windows 번들 정책의 버전·원본 커밋·체크섬은 v0.5.0 발행 산출물에 대한 기록으로 유지.
v0.6.0 Windows 번들은 정식 산출물 확정 후 별도 준비.
