# /auth 기준 UI 일관성 수정 계획

## 목적과 기준

홈, 비교 및 배포, 실행 기록, 사용자 관리, 설정을 인증 관리와 같은 글자·입력·버튼·패널·목록 규격으로 정리한다. 근거는 `working/ui-audit-20260930/review.md`와 화면 측정 자료다.

- 본문·설명·입력 글자: 12px 전후. 표 제목과 보조 버튼은 11.2px 이상.
- 기본 입력 높이: 44px. 주요 버튼: 최소 45px. 보조 버튼: 최소 36px.
- 패널: 모서리 18px, PC 여백 23px 25px. 모바일은 기존 반응형 여백 사용.
- 목록: 공통 표의 헤더·행·상태·액션 표현 사용. 좁은 화면에서는 표 내부 가로 스크롤.
- 등록: 목록을 먼저 보여주고 등록 버튼에서 공통 모달 열기. 오류는 모달 안에 표시하고 성공 후 닫기·목록 갱신. 취소 시 임시 입력 폐기.
- 페이지별 작업 순서와 서버 API, 인증·권한·배포 조건은 유지한다. 이전에 삭제한 소개·토큰 저장 안내 문구를 되살리지 않는다.

## 구현 순서

### 1. 공통 규격과 인증 모달

- CSS 변수와 공통 클래스에 글자·필드·버튼·패널 기준을 모은다. 페이지별 작은 글자 및 중복 덮어쓰기를 정리한다.
- Salesforce/Git 모달의 닫기 버튼, 입력 높이, 라벨, 여백을 맞춘다.
- 기존 `ConnectionDialog`, `ConnectionTable`을 재사용하거나 최소 범위로 일반화한다. 화면별 임의 스타일 추가를 줄인다.
- 키보드 포커스, Escape 닫기, 처리 중 닫힘 방지, 닫은 뒤 트리거 포커스 복귀를 유지한다.

### 2. 사용자 관리

- 사용자 생성 폼을 `사용자 생성` 버튼의 모달로 이동한다.
- 등록 사용자 목록을 사용자·역할·상태·관리 열의 공통 표로 표시한다. 역할 변경과 활성화/비활성화 동작 유지.
- Org 실행 권한 목록을 Org·사용자·부여일·관리 열의 표로 표시하고 `실행 권한 추가` 폼을 모달로 이동한다.
- 역할 기준은 짧은 접이식 도움말로 정리해 목록의 우선순위를 높인다.
- 작은 글자·버튼 규격과 개수 배지 줄바꿈을 수정한다. 마지막 ADMIN/자기 계정 보호와 오류 표시는 유지한다.

### 3. 설정

- UI 서버 정보와 비교 및 배포 설정을 공간 낭비 없는 그리드로 배치한다. 좁은 폭에서는 한 열로 전환한다.
- 설정의 두 입력칸을 균형 있게 배치하고 저장 버튼은 독립된 액션 행에 내용에 맞는 폭으로 둔다.
- 상단 설정과 하단 Git 영역의 제목 아이콘, 설명, 입력칸, 버튼 규격을 맞춘다.
- 허용 IP 목록을 표로 표시하고 IP 등록 폼을 모달로 이동한다.
- Git 프로젝트 가져오기 폼은 `프로젝트 가져오기` 버튼의 모달로 이동한다. 저장소 확인→선택→가져오기 흐름과 기존 오류·진행 상태를 유지한다.
- 서버 프로젝트·등록 배포 브랜치·내 Git 프로젝트의 반복 항목에 공통 표 규격을 적용한다. 빈 목록 및 권한별 액션 상태를 유지한다.

### 4. 실행 기록·배포·홈

- 실행 기록: 필터와 글자 크기를 맞추고 종류·대상·상태·시간·상세 열을 가진 표로 정리한다. 기존 상세 이동과 표시 정보를 보존한다.
- 비교 및 배포: 단계별 구조는 유지하면서 설명·입력·보조 버튼 크기를 통일한다. 64px 메타데이터 버튼은 공통 주요 버튼 높이로 정리한다.
- 홈: SAFE BY DEFAULT의 불필요한 최소 높이와 장식 공간을 줄인다. 최근 실행과 요약 카드 글자 크기를 맞춘다. 삭제된 문구는 추가하지 않는다.

## 역할 분담

1. 주 에이전트: 계획 작성 완료 후 GPT-6 Luna, reasoning high 에이전트에 구현 위임.
2. Luna: 계획 전체 UI 구현, 바뀐 사용자 흐름에 필요한 기존 E2E 갱신과 집중 회귀 검증, `npm run build` 실행, 변경 파일·결과 보고.
3. 주 에이전트: 변경 검토, 부족한 부분 보완 요청, 빌드 산출물 확인, 기존 서버의 실행 인자·환경을 유지한 재시작, 새 UI 자산 제공 확인, 최종 브라우저 점검.

## 완료 기준

- `npm run typecheck`, `npm run quality`, `npm run build` 성공.
- 인증, 사용자 관리, 설정, 실행 기록, Git 관련 기존 E2E 회귀 검증 성공. 새 모달은 열기/취소/오류/성공과 목록 갱신을 테스트 데이터로 확인.
- 6개 페이지를 1920·1440·768·430·390·320px에서 렌더링한다. 페이지 가로 넘침·컨트롤 겹침·읽을 수 없는 축소 글자가 없어야 한다.
- 모바일은 320·390·430px에서 별도 확인하며 터치 입력과 짧은 화면 높이에서도 컨트롤에 접근할 수 있어야 한다.
- SF/Git 및 새 등록 모달의 PC·모바일 키보드/반응형 동작 확인. 테이블 가로 넘침은 컨테이너 내부로 제한.
- 실제 서비스 UI 파일로 변경 후 스크린샷을 남기고, API를 대체한 검증과 실제 서비스 반영 증거를 구분한다.
- 현재 사용 중인 서버 재시작 후 새 자산 URL의 응답과 브라우저 렌더링 확인.
- 커밋·push·PR·병합은 이 작업에 포함하지 않는다. 기존 작업 파일과 실계정·실제 Org·저장 설정을 보존한다.
